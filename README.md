# wspc

Official TypeScript SDK and CLI for [wspc.ai](https://wspc.ai).

> Status: **v0 walking skeleton.** Covers the todo domain only.

## Install

```bash
npm i -g @wspc/cli
```

## Quick start

```bash
wspc login
wspc todo add "Buy milk"
wspc todo ls
```

See full docs at https://wspc.ai/docs (coming soon).
