# Triage labels

Engineering skills 使用五個 canonical triage roles。WSPC todos 以 tags 表示這些 roles。

| Skill role | WSPC tag | 意義 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer 尚未評估 |
| `needs-info` | `needs-info` | 等待 reporter 提供更多資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格與決策完整，可交給 agent 執行 |
| `ready-for-human` | `ready-for-human` | 需要明確的人類決策、權限或操作 |
| `wontfix` | `wontfix` | 已決定不處理 |

當 skill 提到其中一個 role 時，使用表中對應的 WSPC tag。可直接修改右欄，以配合未來的 tracker vocabulary。
